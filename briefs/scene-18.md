# 18 Agent 与长程任务 / Agents & Long-Horizon Tasks

- 年代：2025-2026
- 风格组：data
- 文件：`src/scenes/scene-18.js`
- 量化：否

## 一、核心视觉元素

- **全屏深蓝工作空间**：`#060a16` 底 + `#1a2750` 暗层；青蓝 `#63dfff` 的循环轨道/步骤牌，暖琥珀作为“完成/记忆”信号；背景有很淡的网格、长上下文细带、工具架。
- **Agent 循环**：中央或右侧一条**环形轨道**，上面串着 6–10 个步骤牌/工具节点；环内是主角的“工作台”，环外有工具带、记忆架、待办清单。
- **工具带**：一圈抽象工具，只做几何剪影——锤子/扳手/文件夹/终端窗/画笔/放大镜等，**不出现真实产品、图标、品牌**；工具柄/头用蓝/铜/薄荷色，像一套旧工具。
- **记忆架/长上下文**：一排半透明卡片/书脊/带标签的抽屉，卡片上只有抽象符号/短编号；一条很长的上下文细带从左侧绕到环上。
- **待办清单**：一条很长的纸带/清单，几个抽象勾选框，完成一个亮一个；可以出现 `1/2/3` 或勾/叉，不写长任务描述。
- **环形工具带**：y≈500 的环形/带状轨道，作为“路”；表面有工具槽、步骤编号、0/1 反馈脉冲；从第 17 版块分叉轨道接过来。
- 禁止：真实人物/公司/产品/标志/工具品牌/聊天 UI；真实 Agent 产品界面；代码雨；机器人形象。

## 二、主角（智能意象）形态

- 第 17 版块的分叉步骤牌在这里变成一枚**环形 Agent token**：一个青蓝小环/轨道结，环内保留暖赭火种，环外拖着一小段循环纸带；像一枚会自己绕圈的工牌。
- 运动：**滑—绕—试—回—再绕**；两拍 1s。它沿环形工具带滚动，环上的步骤牌依次亮；失败时纸带抖一下，重试时环收紧。
- 与上一版连续性：同一颗暖火种从分叉步骤牌中心移到环心；分叉轨道接成环。
- 与下一版连续性：结尾环/轨迹散成真实世界的城市网格/屏幕边框，接锁定的第 19 版块；不修改第 19 版块。
- 接触方式：沿环形工具带滑动；停下时环底与带面接触，步骤牌/工具槽亮起。

## 三、路与环境

- **路**：y≈500 的**环形工具带/长程任务带**，宽 58–70；表面有工具槽、步骤编号、0/1 反馈脉冲、待办勾选框；从第 17 版块分叉轨道接过来。`drawRoad` 用同一材质覆盖默认路带 y≈470–530。
- 环境：环形轨道在中右，工具带在外圈，记忆架在右侧/上方，长上下文细带从左侧绕入，待办清单在下方；标题区留空；背景有很淡的网格/工具影子。
- 入口：第 17 版块的步骤牌接成环；分叉轨道变成环形工具带；奖励星收成环上的小铆钉。
- 出口：环/轨迹散成城市网格/屏幕边框；工具带变成第 19 版块的真实世界轨迹（第 19 版块锁定，不画它）。

## 四、构图与镜头

- 1000×1000 作画空间，默认 16:9；标题卡固定 x=300、y=362；标题区 x≈150–450 / y≈280–430 留空。
- 环形轨道约 (680,380)，半径 160–200；工具带外圈/步骤牌在环上；记忆架约 x=780–950、y=260–560；待办清单约 x=480–760、y=600–740；主角在 y≈480–500 的环形工具带上。
- 镜头默认跟拍，不做额外推拉；高光靠工具失败/重试、记忆卡亮、待办勾选、环闭合、完成脉冲完成。
- 画面重心：主角/工具带在下部，环/记忆架在右，标题在左上。

## 五、三小节节拍

- **第 1 小节（0–2s，进场）**：环形工具带从左边接上；环上的步骤牌/工具槽逐个亮；长上下文细带从左侧绕入；记忆架出现；主角环 token 从左侧滚入，第一张待办卡出现。
- **第 2 小节（2–4s，高光）**：主角沿环走，先调用第一个工具——工具槽亮起，反馈脉冲是**叉**（失败）；纸带抖一下，它退回，换第二个工具，反馈脉冲变成**勾**。它继续绕，调用记忆架上的卡片，上下文细带变长，待办清单一条条勾上；但每完成一项，清单又长出一小段，环也跟着变大。最后它绕回起点，环闭合，所有工具槽/记忆卡/待办勾同时亮起，一颗完成脉冲沿环走一圈；主角停住，火种闪一下；定格约 1s。梗是“它终于能长时间自己做事，第一件事是给自己列了一张很长的待办清单”，不解释、不写长任务文字。
- **第 3 小节（4–6s，离场）**：环/轨迹松开，散成城市网格/屏幕边框；工具带变成真实世界轨迹，接锁定的第 19 版块。
- 循环动作：两拍（1s）；滚动/试/回/再绕对齐节拍。

## 六、转场

- **从第 17 版块进入**：步骤牌接成环；分叉轨道变成环形工具带；奖励星收成环上铆钉。
- **离开到第 19 版块**：环/轨迹散成城市网格/屏幕边框；工具带变成真实世界轨迹。第 19 版块锁定，不修改它；19→20 转场后置。
- **到第 20 版块**：锁定的第 19 版块负责 19→20 的转场；第 18 版块不画第 20 版块。

## 七、标题卡

- 标题：`Agent 与长程任务` / `AGENTS & LONG-HORIZON TASKS` / `2025-2026`，data 组。
- 深底上的年代小字（data 的 soft 深蓝）对比不足：在年代文字后加一条**浅青/奶油色窄带**，位置不变；主标题/英文保持原排版。
- 标题卡只由当前版块绘制：沿用 `currentBlockAt()` 门控；镜头提前看到下一段时不画下一段标题。

## 八、技术约束

- 只改 `src/scenes/scene-18.js`；不改 `src/kit`、`src/beat`、`src/main`、其他 scene、placeholder、锁定的 scene-19；不安装依赖、不联网、不使用外部图片/字体/p5.brush。
- 用 `draw` 画全屏工作空间/环/工具带/记忆架/待办/标题；`drawRoad` 画 y≈500 环形工具带并覆盖默认路带 y≈470–530；`drawActor` 画环形 Agent token。
- `drawActor` 直接吃世界坐标 `state.x`；要复用局部布局先 `p.translate((state.blockIndex - 1) * 1000, 0)`，不要把 `state.x` 减偏移后当世界坐标画。
- 确定性：`hash2` / `mulberry32` / `smoothstep`；禁止 `Math.random` / `Date.now`；同 t 重渲逐像素一致。
- 禁止 `p.background()`；直接改 `p.drawingContext` 的渐变/虚线/混合模式要 `save()/restore()`；辉光用低 alpha 叠加，不要大半径 blur。
- **禁止 `bezierVertex` / `curveVertex` / bezier-only 闭合形状**：p5 2.x 会读空内部点导致整页 `__ready` 失败；环/轨迹/工具轮廓用采样点 `p.vertex` 折线、圆角矩形或分段 line。
- 不出现真实人物/公司/产品/标志/工具品牌/受保护角色/聊天 UI/机器人形象；工具只用几何剪影；任务文字只用编号/勾/叉/短符号。
- 静态优先：重点做 localT≈1.5（标题+环形工具带/记忆架/待办进场）和 localT≈3.0（工具失败→重试→记忆→待办勾选→环闭合/完成脉冲/定格）；第 1/3 小节可用确定性简化状态。

## 九、验收

- 第一眼能看出“环形 Agent 轨道 + 工具带 + 记忆架 + 长上下文 + 待办清单 + 环形 token 主角”，不是真实 Agent 产品界面或机器人。
- 主角是环形 token/轨道结，滑/绕/试/回节奏明确，和第 17 版块是同一颗火种。
- 第 2 小节工具失败→重试、记忆卡亮、待办勾选、环闭合、完成脉冲、定格读得懂。
- 标题卡位置/字号不变；data 年代带可读；全屏背景没有默认路面横带。
- 工具带在 y≈500 保持，能接上锁定的第 19 版块的真实世界轨迹。
- 静态帧与接触表通过；同 t 重渲一致。
