# 14 注意力机制 / Attention

- 年代：2017
- 风格组：data
- 文件：`src/scenes/scene-14.js`
- 量化：否

## 一、核心视觉元素

- **全屏深蓝序列空间**：`#060a16` 底 + `#1a2750` 暗层；青蓝 `#63dfff` 的 token/连线，少量琥珀作为高注意力权重；token 卡像发光的半透明薄片，不是现代聊天 UI。
- **token 序列**：一排 6–8 张抽象 token 卡沿 y≈500 的序列带排列，卡片上只有几何符号/单个字母（如 `A`、`B`、`C`、`?` 和一个小句点），不写真实句子、不出现真实产品/公司/标志。
- **Q/K/V 网格**：右上方一块 3 行小矩阵/网格，标 `Q`、`K`、`V`；每格是小光点/短线，旁边有 softmax 权重条。
- **注意力光束**：从主角 query token 出发的若干条发光细线，连向其他 token；线宽/亮度对应权重；权重条从 0 到 1 排开。
- **序列带**：y≈500 的扁平 token 带/数据带，作为“路”；表面有 token 槽位、位置刻度、很淡的并行线；从第 13 版块张量带接过来。
- 禁止：真实人物/公司/产品/标志；真实聊天/模型界面；长句文本；代码雨；发光大脑。

## 二、主角（智能意象）形态

- 第 13 版块的梯度方块在这里变成一枚**query token/注意力头**：一张小的青蓝发光卡片（或三棱薄片），正面是 `Q` 或一个箭头，中心保留暖赭火种；边缘有几条可伸缩的光线。
- 运动：**滑—停—扫—再滑**；两拍 1s。停下时从卡片边缘伸出注意力光线，扫过序列；光线回缩时带一点光尘。
- 与上一版连续性：同一颗暖火种从梯度方块中心移到 query 卡中心；层切片变成 Q/K/V 薄片。
- 与下一版连续性：结尾注意力光线收束成一束参数线，token 卡压成参数块，序列带变宽成参数传送带，进入第 15 版块。
- 接触方式：沿 token 带滑行；停下时卡片下沿对准一个 token 槽位，槽位亮起。

## 三、路与环境

- **路**：y≈500 的**token 序列带/扁平数据带**，宽 52–64；表面有 token 槽、位置刻度、并行细线；从第 13 版块张量带接过来。`drawRoad` 用同一序列带材质覆盖默认路带 y≈470–530。
- 环境：token 序列沿下部展开，Q/K/V 网格在右上，softmax 权重条在右侧，标题区留空；背景有很淡的网格和序列位置线。
- 入口：第 13 版块的网络层摊平成 token 卡；梯度方块展开成 query 卡；张量带变成 token 序列带。
- 出口：注意力光线收成一束，token 卡压成参数块；序列带变成第 15 版块的参数传送带。

## 四、构图与镜头

- 1000×1000 作画空间，默认 16:9；标题卡固定 x=300、y=362；标题区 x≈150–450 / y≈280–430 留空。
- token 序列约 x=430–930、y=450–560；Q/K/V 网格约 x=650–930、y=260–410；softmax 权重条约 x=760–930、y=560–690；主角在 y≈480–500 的序列带上。
- 镜头默认跟拍，不做额外推拉；高光靠注意力光线扫过、权重条倾斜、光束钉在句点上、定格完成。
- 画面重心：主角/序列带在下部，Q/K/V 网格/权重在右上，标题在左上。

## 五、三小节节拍

- **第 1 小节（0–2s，进场）**：token 序列带从左边接上；6–8 张 token 卡依次亮起；Q/K/V 网格出现；主角 query 卡从左侧滑入，第一次伸出注意力光线。
- **第 2 小节（2–4s，高光）**：主角停在一个槽位，注意力光线向所有 token 展开；权重条开始倾斜，softmax 把大部分权重给了一个 token。它继续扫，光线越来越集中，最后**全部钉在序列末尾的小句点上**——那个 token 几乎不携带信息，但权重条显示 99%。主角的 query 卡歪了一下，光线想收回来又被句点吸住；权重条卡在 99%，火种闪一下；定格约 1s。梗是“它学会了看哪里重要，结果盯住了句号”，不解释、不写长句。
- **第 3 小节（4–6s，离场）**：光线从句点上松开，收成一束；token 卡压成参数块，序列带变宽成参数传送带；主角缩成一枚参数标签，进入第 15 版块。
- 循环动作：两拍（1s）；滑行/停靠/光线伸展对齐节拍。

## 六、转场

- **从第 13 版块进入**：网络层摊平成 token 卡；梯度方块展开成 query 卡；张量带变成 token 序列带。
- **离开到第 15 版块**：注意力光线收成参数线；token 卡压成参数块；序列带变成参数传送带。
- **到第 16 版块**：第 15 版块再把参数/开放权重展开成多模态信号；第 14 版块不画第 16 版块。

## 七、标题卡

- 标题：`注意力机制` / `ATTENTION` / `2017`，data 组。
- 深底上的年代小字（data 的 soft 深蓝）对比不足：在年代文字后加一条**浅青/奶油色窄带**，位置不变；主标题/英文保持原排版。
- 标题卡只由当前版块绘制：沿用 `currentBlockAt()` 门控；镜头提前看到下一段时不画下一段标题。

## 八、技术约束

- 只改 `src/scenes/scene-14.js`；不改 `src/kit`、`src/beat`、`src/main`、其他 scene、placeholder；不安装依赖、不联网、不使用外部图片/字体/p5.brush。
- 用 `draw` 画全屏序列空间/token 卡/QKV 网格/权重条/标题；`drawRoad` 画 y≈500 token 序列带并覆盖默认路带 y≈470–530；`drawActor` 画 query 卡和注意力光线。
- `drawActor` 直接吃世界坐标 `state.x`；要复用局部布局先 `p.translate((state.blockIndex - 1) * 1000, 0)`，不要把 `state.x` 减偏移后当世界坐标画。
- 确定性：`hash2` / `mulberry32` / `smoothstep`；禁止 `Math.random` / `Date.now`；同 t 重渲逐像素一致。
- 禁止 `p.background()`；直接改 `p.drawingContext` 的渐变/虚线/混合模式要 `save()/restore()`；辉光/光线用低 alpha 叠加，不要大半径 blur。
- 不出现真实人物/公司/产品/标志/受保护角色/聊天 UI/长句文本；token 只用几何符号/单个字母/问号/句点。
- 静态优先：重点做 localT≈1.5（标题+token 序列/QKV 网格进场）和 localT≈3.0（光束钉在句点上、权重条 99%、query 卡歪、定格）；第 1/3 小节可用确定性简化状态。

## 九、验收

- 第一眼能看出“token 序列 + Q/K/V 网格 + 注意力光束 + 权重条 + query 卡”，不是现代聊天 UI 或长句文本。
- 主角是 query token/注意力头，滑/停/扫/光线伸展节奏明确，和第 13 版块是同一颗火种。
- 第 2 小节光束全部钉在句点上、权重条 99%、query 卡歪、定格读得懂；不靠解释文字。
- 标题卡位置/字号不变；data 年代带可读；全屏背景没有默认路面横带。
- 序列带在 y≈500 保持，能接上第 15 版块参数传送带。
- 静态帧与接触表通过；同 t 重渲一致。
