## 各版块落点

### 16 多模态原生统一

- 深蓝信号空间、四路信号流（图像/音频/文本/视频的几何化合成）、中央多面棱镜、共享嵌入星座、y≈500 混合信号带。
- 主角是多信号棱镜/编织结；关键帧四路信号压到同一颗嵌入点，圆形信号也误落到同一点，旁边出现小 `?`/错位环。
- 流线为采样三次贝塞尔 + `p.vertex`，无 `bezierVertex`。

### 17 推理模型与强化学习

- 分叉推理树/迷宫、步骤牌（1/2/3、勾/叉、几何符号）、价值曲线、分叉脉冲、y≈500 分叉轨道。
- 主角是分叉步骤牌；关键帧上路死路打叉、价值曲线下探、回退、下路自指回环、旁支、金色奖励星、价值曲线陡升。
- 推理内容只用抽象符号，不写长思维链。

### 18 Agent 与长程任务
