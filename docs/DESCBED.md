# 《计算之灵》当前画面与音频描述

## 0. 总览

- 片名：《计算之灵——人类如何把思考交给机器》
- 成片时长：137 秒；120 BPM；一小节 2 秒。
- 结构：Intro 0–5 秒，20 个版块，Outro 125–137 秒；第 i 个版块从 `5 + 6 × (i - 1)` 秒开始，每块 6 秒。
- 画面：1920×1080；每个版块在 1000×1000 作画空间内绘制；16:9 相机跟随主角世界坐标；标题卡固定在局部 `x=300, y=362`。
- 风格组：1–4“纸与刻痕”（paper）；5–8“机械与图纸”（mechanical）；9–12“电子与示波器”（electronic）；13–20“数据流与光”（data）。第 20 版块是 data 组的暖白留白反转。
- 时间量化：第 2、4、11 版块的场景内容按 10Hz 更新，相机连续；其余版块连续。
- 画面确定性：所有随机纹理由固定种子 `hash2`/`mulberry32` 生成；同一时刻重渲逐像素一致。
- 输出：浏览器实时预览（播放、暂停、拖动、静音）；Puppeteer 逐帧渲染 → ffmpeg 合成为 MP4 的管线。
- 场景文件：第 8、19 版块文件保持锁定；第 19→20 接缝由第 20 版块一侧叠加暖白羽化。

## 2. 音频

### 2.1 音频系统

- 全部由 Web Audio 程序合成，不使用外部音频采样、真实乐器录音、歌曲或音效库。
- 总谱在 `src/audio/score.js` 中描述为事件表：时间、时长、乐器/音效类型、音高、增益、声像。
- 合成器在 `src/audio/engine.js` 中：振荡器、噪声、滤波器、包络、Ping-pong 式单延迟、卷积混响、压缩器、限幅器。
- 主输出：master gain 0.672（整体 −3dB 余量）→ 压缩器（threshold −16dB、ratio 3）→ 限幅器（threshold −2dB、ratio 20）→ 输出。
- 音乐与物理音效分总线：音乐经过 musicEase 与 19 版块推进 gain 后进主总线；音效经 body/presence EQ 后进主总线。
- 高光处理：第 2 小节 18 个高光/定格音效点触发 SFX body/presence 轻微提升（300Hz +1.8dB、1.6kHz +3.2dB）；只有持续 ≥0.24 秒的点才让音乐在 0.3 秒内缓慢下压 −2.5dB、结束后 0.5 秒恢复，不做瞬间压音。
- 19 版块：音乐推进 gain 从 17 末开始蓄力，19 中后段推到约 +4.6dB，送进限幅器制造全体合奏的响度顶点。
- 混响：约 2.1 秒程序生成脉冲；延迟：0.375 秒附点八分，反馈 0.27；混响/延迟返回经过音乐总线。
- 实时预览：用户点播放时创建 AudioContext；调度器每 80ms 向前看约 0.9 秒，从当前播放时间续排。
- 暂停/拖动：停止当前源并从新时间重新调度；静音按钮控制 master gain。
- 离线导出：`npm run render:audio` 使用 OfflineAudioContext 渲染 137 秒、44.1kHz、16-bit、立体声 WAV，与实时版共用同一份 score/engine。
- 当前实时预览已包含最新乐器层、高光 EQ/缓慢让路与 19 版块响度曲线；最近一次离线 WAV 生成于本轮早期混音，尚未覆盖后续层增益/限幅调整。

### 2.2 主旋律与和声

- 主旋律固定为三小节 D 小调主题，所有版块保持同一组音高关系：
  - 第 1 小节：D4–F4–A4–C5
  - 第 2 小节：Bb4–A4–F4
  - 第 3 小节：G4–A4–D5
- 和声循环：Dm–Bb–F；低音：D2–Bb1–F2。
- 每个版块只更换主奏音色、八度、节奏织体与伴奏层；不另写新旋律。
- 主题变体：5–8 加高八度回声；9–12 加短促高八度；13–16 加 shimmer 叠层；17 加钢琴高音铃；20 加玻璃回声。

### 2.3 13–19 的累积乐器层

- 13：低音弦乐进入并持续到 19。
- 14：高音玻璃/钟进入。
- 15：铜管短和弦进入。
- 16：高弦长音进入；16 原主旋律/音色/节奏不变。
- 17：大提琴低音线进入。
- 18：定音鼓进入。
- 19：唱诗班进入，13–19 全部乐器层合奏；19 为全片音乐最高点，音乐总线推进限幅器。
- 各层在进入版块的第一个小节有一小段“亮相”重音；层增益随版块递增。20 全部退出，只留留白与火种余韵。
