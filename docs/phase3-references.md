### 为什么不安装 p5.brush

p5.brush 2.2.3 的 MIT 许可没有问题，但参考项目的接入方式依赖 WebGL `createFramebuffer`、`brushLib.load()` 和内部 compositor flush，并且有缩放坐标的运行时补丁。我们的工程是 **p5 2.x 2D Canvas + 纯 `renderAt(t)` + 离屏快照**，直接引入会多出一套渲染状态和 flush 时序，风险大于收益。

按 TASK8 第 3 条“优先提取核心渲染公式/参数，重写到自己的 scene 文件”，A 批把纸、泥、墨、铜的公式用现有 p5 图元重写。以后如果某个笔触确实需要更丰富的笔毛，再考虑在 **scene 内部**做局部封装，仍然不动 `kit/beat`。

### 不采用 / 不越界

- 不复制 huashu 的引擎代码、字体、笔触数据、角色美术、场景资产。
- 不复制 The Pelican Test 的代码、影片、帧、音频、构图、文案和笑话；不 fork。
- 不写真实阿拉伯经文/书法作品；只做抽象几何花饰。不出现真实产品、标志、真实人物。
- 不把参考项目的具体构图、角色、道具“顺手拿来”；只迁移材料语言与参数关系。
- 外部 clone 只读；不运行其中的脚本，不从中安装依赖。

## 二、四版块的具体用法

### 02 数与形 · 湿泥板

**借鉴：** `01_cave.md` 的岩面高度场/颗粒/裂纹，`02_egypt.md` 的平涂+轮廓+斑驳表面，The Pelican Test `paper.js` 的 papyrus/clay 纸面构造思路；`04-纯代码绘制.md` 的“平涂底稿 → 风格渲染 → 小物件 → 主角 → 会动高光”五层顺序。

**重写为：**

- **泥面底**：`#c79a63` 湿泥底 + 2–3 层低频噪斑（亮/暗各一层，α 0.05–0.15）+ 细沙颗粒（200–400 个 1–3px 点）+ 指抹弧（少量半透明长弧）。不逐像素跑 1000² 高度场；用低分辨率斑块和 p5 图元保持 60fps。
- **压印楔形**：不是画线。每枚 = 三角形楔口（深褐内壁）+ 短尾 + 两侧翻起的泥唇（亮边）+ 少量泥屑；压印处泥面微微鼓起。刻痕颜色沿用 paper 组的 `#33291f`，不要压黑。
- **裂纹**：随机游走，每步转角约 ±0.45 rad、步长 14–40、12% 分叉；主裂缝下垫一条 +1.6px 的亮线，做出“裂开有厚度”的观感（来自 `01_cave` 的裂缝做法，重写）。
- **4×4 表**：右侧 x≈520–900、y≈330–640；格线是压出来的凹槽（暗线 + 相邻亮边），每格一个小楔形数字/平方数。表格不能压标题卡（标题在 x=300, y=362 附近）。
- **高光**：最后一下过深 → 16 块方形泥片浮起、旋转、拼成完整正方形；尖笔停住，敲两下，泥粉落下；定格约 1s。16 块用 `hash2` 固定每块的偏移/旋转，不用随机。
- **主角**：青铜/芦苇尖笔，短柄、楔形尖，尖端保留暖赭火种；压—抬—前移—再压。`drawActor` 里用 `state.x`，局部坐标 = `state.x - (state.blockIndex - 1) * 1000`。
- **量化**：`draw` 收到 10Hz 的 `state.localT`；`drawActor`/`drawRoad` 收到原始值，动作要顿挫就在内部 `Math.floor(t * 10) / 10`。

**静态关键帧：** 全局 `t=14.0`（版块内 3.0s），16 块刚拼成正方形、尖笔悬停；标题已淡出。进场帧 `t=12.0`（1.0s）保留标题。

### 03 几何与证明 · 羊皮纸/沙板

**借鉴：** `03_greek.md` 的陶土底纹理与“剪影/刻线/附加色”层级，`12_bauhaus.md` 的几何构成与“先算内框再排格”的尺寸纪律，`22_constructivism.md` 的 45° 网点算法，`15-跨场景风格提炼.md` 的“风格语言与内容分开”。

**重写为：**

- **纸面底**：`#e8dcc0` 羊皮纸；低分辨率 fbm 斑驳 ±30、水平纤维噪声 ±9；300–500 根 8–30px 短纤维（一半褐 α0.05–0.12、一半亮 α0.10–0.22）；2–3 条随机游走裂纹；边缘轻微暗角。不要把纸做成现代笔记本。
- **构造图**：大圆圆心约 (700, 390)、半径约 180；内接三角形；两条平行线；3–4 段虚线圆弧。主线 2.2–2.8px 炭黑/石墨灰；辅助线 0.7–1.2px、α 0.25–0.45；虚线只用于构造弧。
- **证明链**：4–5 个小节点（r≈4–7）用细线连接，节点像被点亮的墨点；最后一个节点留空/半亮，表示“未完成”。
- **铜尺**：y≈630 的薄铜尺，作为路的硬边；黄铜用“底色 + 暗边 + 1px 高光偏移”三段，不用照片。
- **主角**：青铜圆规，顶部铰链里保留暖赭火种；定脚—旋臂—换点—再画。`drawActor` 的局部坐标同样要减去版块起点。
- **高光**：画圆、弦、三角形、证明链；尝试化圆为方，圆规快速旋转，弧线缠成小螺旋；螺旋收住，变成卡在圆边的小正方形；圆规用一条腿敲它，方块不掉；定格约 1s。所有角度/半径由 `localT` 决定，不用随机。
- **不量化**。

**静态关键帧：** 全局 `t=20.0`（版块内 3.0s），小方块卡在圆边、圆规停住；进场帧 `t=18.0`（1.0s）保留标题。

### 04 算法一词的诞生 · 羊皮纸与铁胆墨

**借鉴：** `17_ink.md` 的宣纸纤维/笔压/飞白/墨晕/留白，`51_persian_miniature.md` 的平涂+深褐轮廓+几何纹样+金边，`04-纯代码绘制.md` 的“纸是底、墨只往上加”。

**重写为：**

- **纸面**：`#e7d9b8` 羊皮纸；600–900 根纤维（一半褐 α0.05–0.13、一半亮 α0.12–0.27，A 批降密度，避免 1080p 噪）；横向书写线很淡；纸边有卷起阴影。可以少量金/赭金线，但不要满屏金箔。
- **墨**：铁胆墨深褐 `#2a2118` 左右。墨色分五阶（焦 .9 / 浓 .8 / 重 .6 / 淡 .35 / 清 .15）。笔画参数借鉴 `17_ink`：点列按约 4px 弧长重采样；笔压 `prof(q) = smoothstep(0,head,q) * (1 - 0.7*smoothstep(1-tail,1,q)) * (0.85 + 0.15*noise)`；湿笔芯 α≈0.72；笔毛是连续折线，干笔阈值断开露纸。A 批用 2–3 层半透明偏移线模拟洇开，不依赖大半径 blur。
- **步骤列**：右侧 x≈620–900、y≈450–650；短横线 + 大号 1/2/3 + 墨线/箭头。第 3 步箭头回到第 1 步，形成回路。标题卡在 x=300，步骤列不能压标题。
- **花饰**：只做抽象几何（八芒星/交织线/小方菱形），不写真实经文，不用真实书法。几何纹样用平涂+深褐轮廓，少量旧金。
- **高光**：墨线沿回路打转，笔追自己的线；纸面沿墨线卷成纸螺旋；展开后右下角留下端正的 `algorithm`（通用 serif，不是真实书法）；笔尖在收笔点敲一下；定格约 1s。
- **量化**：同上，`draw` 10Hz；`drawActor`/`drawRoad` 内部需要时再量化。

**静态关键帧：** 全局 `t=26.0`（版块内 3.0s），纸螺旋展开、`algorithm` 已写出、笔尖停在收笔点；进场帧 `t=24.0`（1.0s）保留标题。

### 05 机械计算 · 深木与黄铜

**借鉴：** `12_bauhaus.md` 的几何构成、有限色板、旧纸/丝网不匀墨，`22_constructivism.md` 的 45° 网点公式与“照片剪贴/清晰线”分层，`01_cave.md` 的裂纹/颗粒，The Pelican Test `paper.js` 的纸面/边缘暗角思路。

**重写为：**

- **工作台**：深木 `#2a211a`；200–300 条长而缓的横向木纹（二次曲线，α 0.04–0.12）；少量油渍/金属屑；边缘暗角；不要压成纯黑。
- **黄铜**：`#6e4a22` / `#b8863c` / `#d8a75a` 三段；滑尺、游标、齿轮、算盘杆用“底色 + 径向暗边 + 1px 高光偏移”，不是照片。需要印刷感时可用 `22_constructivism` 的 45° 网点：cell 4.6–7、gain 0.74–0.8、`r = cell*gain*sqrt(1-L)`，所有点并成一条 path 一次 fill。
- **算盘**：右上方一组竖杆与木珠，杆/珠排列像小墙；黄铜+深木；不要抢标题。背景 2–3 个黄铜齿轮缓慢咬合（12–24 齿），蒸汽/油雾很轻。
- **滑尺**：y≈630 横贯，作为路；对数刻度（`log10` 位置）+ 游标；刻度要读得出是计算尺，不是普通尺子。
- **手**：从上方伸入的深色剪影，只做手掌/手指轮廓，不画真人细节、不出现标志；和珠子抢游标。
- **主角**：黄铜/深木算盘珠（可带小齿），内部暖赭火种；咔哒—滑—咔哒；被手推动，也会顶回游标。
- **高光**：珠子对准刻度 → 手把游标推过头 → 珠子顶回 → 再推再顶 → 算盘珠重排成 `0` 或问号 → 齿轮冒汽 → 手竖大拇指 → 珠子冒一小股蒸汽；定格约 1s。手只做剪影，动作笨拙、认真，不卖萌。
- **不量化**。

**静态关键帧：** 全局 `t=32.0`（版块内 3.0s），游标被顶回、算盘呈 `0`、手竖大拇指、蒸汽未散；进场帧 `t=30.0`（1.0s）保留标题。

## 三、工程护栏（四个场景共同）

1. 只改 `src/scenes/scene-0X.js`；不改 `src/kit`、`src/beat`、`src/main`、`src/scenes` 里的其他文件。
2. 不新增依赖、不安装包、不联网、不读取/运行外部 clone 里的代码；外部资料只作为 Markdown 参考。
3. `draw(p, state)` 画全屏背景、表格/构造图、标题；`drawRoad(p, state)` 用同一材料补回 `y=470–530` 的默认路面带；`drawActor(p, state)` 画主角。
4. `drawActor` 拿到的是**世界坐标**：`state.x` 是全局主角 x；场景局部 x = `state.x - (state.blockIndex - 1) * 1000`。
5. 标题卡固定 `x=300, y=362`，`alpha = 1 - smoothstep(2.2, 2.8, t)`；标题区（约 x 150–450、y 280–430）不要放表格/步骤/齿轮。
6. 禁止 `p.background()`（会清整张画布）；用填充矩形。直接操作 `p.drawingContext` 的渐变/虚线/混合模式必须 `save()/restore()`；p5 2.x 的 fill 缓存会因裸改 `ctx.fillStyle` 失步。
7. 随机只用 `hash2` / `mulberry32`；禁止 `Math.random` / `Date.now`。同 t 重渲必须逐像素一致。
8. 字体只用现有通用族（`serif` / `sans-serif` / `monospace`）；不引入字体文件。`algorithm` 用通用 serif，不伪造书法。
9. 不出现真实产品/标志/真实人物；不写真实经文/书法；第 5 版块的手只做剪影。
10. A 批是**静态图优先**：重点做进场与第 2 小节关键定格；第 1/3 小节可以保留确定性的简化状态，不做完整动画打磨。

## 四、A 批执行

四个子代理，一人一个文件，互不越界：

- `src/scenes/scene-02.js` — 数与形
- `src/scenes/scene-03.js` — 几何与证明
- `src/scenes/scene-04.js` — 算法一词的诞生
- `src/scenes/scene-05.js` — 机械计算

每个代理交付：场景代码、`node --check` 通过、静态关键帧与进场帧的渲染建议/坐标说明；不在代理内跑浏览器，渲染与接触表由主进程统一做。

统一静帧时间：

| 版块 | 进场（标题） | 关键定格 |
|---|---:|---:|
| 02 | 12.5s | 14.0s |
| 03 | 18.5s | 20.0s |
| 04 | 24.5s | 26.0s |
| 05 | 30.5s | 32.0s |

进场帧比原计划后移 0.5s，是为了让版块切换点的前一段接缝只留在画面最左约 30–60px，同时标题仍完整在场。标题卡只由“当前版块”绘制，避免镜头提前看到下一段时把下一段标题带进上一段的第 2 小节；占位版块也做了同样处理。

验收：第一眼能读出材料/时代/主角；标题卡不变；全屏背景没有默认路面横带；关键定格读得懂；同 t 重渲一致；1080p 可读。
