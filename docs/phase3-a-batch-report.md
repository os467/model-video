## 各版块落点

### 02 数与形

- 全屏湿泥 `#c79a63`，低频泥斑、沙粒、指抹弧、凹坑、边缘裂纹；没有逐像素高度场。
- 右侧 4×4 表：x520..880 / y330..610，压槽格线（暗线+亮边），格内方块小序号与平方数（风格化六十进制，非严格考古字形）。
- 基线凹槽 y=630.5；尖笔为青铜/芦苇 split tip，尖端暖赭火种，压—抬—前移。
- 关键帧：16 块泥片裂缝 5 单位、整体浮起 10 单位，带阴影和轻微残旋；尖笔停在表格左侧。泥片缝和浮起量在初版基础上加大，1080p 下能读成 16 块，而不是一张连续网格。
- 年代小字后面改成深泥色窄带，文字位置/字号不变。

### 03 几何与证明

- 全屏羊皮纸 `#e8dcc0`，短纤维、低频斑、细裂纹、极淡辅助网格；大圆/内接三角形/平行弦/冷灰蓝虚线弧/证明链。
- 青铜圆规铰链保留暖赭火种；关键帧停在圆左下角、一条腿点着卡在圆边的黄铜小方块；证明链前四节点亮、最后空心。
- 初版 `drawActor` 把 `state.x` 又减了版块偏移，圆规被画到镜头外；已改为直接使用世界坐标。默认路面带改成**整块场景重绘**（同一套纸纹/裂纹/构造/标题）再画铜尺，避免补丁边缘出现亮带。场景绘制成本约翻倍，1080p 静态与当前预览正常，后续 60fps 总检时再量。

### 04 算法一词的诞生

- 全屏羊皮纸 `#e7d9b8`；确定性纤维、横向书写线、边缘暗角/卷角；抽象几何花饰，不写真实经文。
- 铁胆墨五阶；步骤 1/2/3 在右侧，第 3 步箭头回到第 1 步；`algorithm` 在右下，通用 serif。
- 关键帧：纸卷痕展开、`algorithm` 写成、笔尖钉在收笔点，约 1s 定格；纸面只做卷带/同心痕/卷角的 2.5D 画法，不是真实翻页。
- `drawActor` 用 `p.translate(blockOrigin)` + 局部坐标，世界位置正确。

### 05 机械计算

- 深木台面、长缓木纹、油渍/铜屑；黄铜三色齿轮/算盘/计算尺；log10 刻度；手只做深色剪影。
- 关键帧：算盘珠排成 0 环，珠子顶住游标，手在右侧竖大拇指，齿轮/珠子轻蒸汽，珠子和尺面留下残影/刮痕。
- 手部入场从 localT 1.3 推迟到 1.65–2.0，标题帧不再顶着一只大手。
- 手是 capsule/椭圆剪影，不是写实解剖；关键帧会遮住主齿轮一部分，这是“手与工具互动”的取舍。

## 批内统一修正（主进程）

1. **`drawActor` 世界坐标**：第 2、3 版块初版都多减了版块起点，主角被画到镜头外；已修。第 4 版块用 `translate(blockOrigin)` 的方式本来就是对的，第 5 版块用 `state.x` 画、局部值只算滚动角。
2. **标题卡只由当前版块绘制**：版块 2–5 和共享 `src/scenes/placeholder.js` 都加了 `currentBlockAt()` 门控。镜头提前看到下一段时，不再把下一段标题带进上一段的第 2 小节。标题卡位置/字号/淡出时机未动。
3. **未轮到的占位版块只保留底材**：`placeholder.js` 在非当前版块时提前返回，不再画边框、大号编号、标题、高光占位和 `PLACEHOLDER` 标签；当前版块仍完整显示占位。
4. **第 2 版块**：16 块泥片缝 1.4→5.0、浮起 7→10、残旋 ±0.008→±0.018；年代带改为深泥色。
5. **第 3 版块**：全屏重绘替代补带；删掉未使用的补带函数。
6. **第 5 版块**：手部入场推迟。

- 第 2 版块楔形数字是风格化写法，不是严格考古字形。
